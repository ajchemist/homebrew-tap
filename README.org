* se-sshctl
: brew install ajchemist/tap/se-sshctl

Stable releases are received from =ajchemist/se-sshctl= through an authenticated
=repository_dispatch= carrying the release's universal macOS binary tarball. The
update workflow verifies that asset against the release's =SHA256SUMS= and opens a
Formula update PR pointing at it (no source build, no bottle). The PR is style
checked, audited, installed and =brew test=-ed on macOS 26; after that exact PR
commit passes, it is rebase-merged into =master=.

The =se-sshctl= release workflow and this tap both require =HOMEBREW_APP_ID= as a
repository variable and =HOMEBREW_APP_PRIVATE_KEY= as a repository secret.
